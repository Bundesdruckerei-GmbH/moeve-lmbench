# Contributing

Thanks for your interest in MÖVE LMBench.

## Bug reports and feature requests

Open an issue on GitHub. For bugs, include reproduction steps and your environment (Python version, OS, provider).

## Pull requests

1. Fork the repo and create a branch from `main`.
2. Install dependencies with `uv sync`.
3. Run `prek run --all-files` and `uv run pytest` before submitting.
4. Open a PR against `main` describing the change.

We respond on a best-effort basis.
